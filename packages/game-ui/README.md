# @geo/game-ui

Game-specific UI components for the Geo platform.

## Components

- `MultipleChoice` – grid of answer options with correct/wrong feedback
- `GameTimer` – countdown timer with progress bar and warning state
- `ScoreDisplay` – shows total score, correct count, and streak
- `ResultPanel` – feedback panel showing correct/wrong with score delta

## Usage

```vue
<script setup>
import { MultipleChoice, ScoreDisplay } from '@geo/game-ui'
</script>
```
