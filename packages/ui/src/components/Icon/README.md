# Icon

Renders an SVG icon by name using open-icon-svg.

## Usage

```vue
<Icon name="action/check" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| name | string | required | Icon identifier (e.g. 'action/check') |
| size | Size | 'medium' | Icon size |
| color | Color | — | Icon color |
