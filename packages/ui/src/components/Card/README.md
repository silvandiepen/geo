# Card

A content container component with optional title, subtitle, and grouping.

## Usage

```vue
<Card title="My Card">Content here</Card>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| title | string | — | Card heading |
| subtitle | string | — | Card subheading |
| color | CardColor | — | Color variant |
| type | CardType | — | Visual type |
