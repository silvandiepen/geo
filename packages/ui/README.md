# @geo/ui

Reusable UI components for the Geo platform.

## Components

- `BaseButton` – button with variant (primary/secondary/danger/ghost) and size (sm/md/lg)
- `BaseCard` – card container with optional hover effect
- `BaseInput` – text input with label support
- `BaseModal` – teleported modal dialog

## Usage

```vue
<script setup>
import { BaseButton, BaseCard } from '@geo/ui'
</script>
```

Requires SCSS support in the host app.
