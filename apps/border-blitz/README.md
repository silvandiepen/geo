# Border Blitz

Name all neighbors of a given country before the timer runs out.

## How to Play
1. A country is shown on screen
2. Type the names of all its neighboring countries
3. You have 60 seconds
4. Wrong guesses reduce your score

## Scoring
- Score = (found / total) * 100
- -5 points per wrong guess
- Minimum: 0

## Development
```bash
pnpm dev  # http://localhost:5177
```
