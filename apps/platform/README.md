# Platform App

The central hub for the Geo geography games platform.

## Features

- Lists all available games with descriptions
- Navigation links to each game app
- Responsive grid layout

## Development

```bash
pnpm dev
```

Runs on `http://localhost:5173`

## Games

| Game | Port | Description |
|------|------|-------------|
| Walk It | 5174 | Navigate between countries via borders |
| Guess The Flag | 5175 | Identify countries from flags |
| Guess By Hints | 5176 | Guess country from clues |
| Border Blitz | 5177 | Name all neighbors of a country |
| Capital Match | 5178 | Match countries to capitals |
